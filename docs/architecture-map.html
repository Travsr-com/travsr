01 — Structure

Teen layers

Crates ko alphabetically mat padho — data ke direction me padho. Har crate teen me se ek layer pe baithta hai, aur dependency hamesha neeche ki taraf behti hai.

Write path

Disk pe source → graph.db. Yahan trust boundary aur sandbox rehta hai.
travsr-core1,557

Data model. VName, NodeId, EdgeKind, Node, Edge. Har crate isi pe khada hai.

travsr-analysis10,602

Tree-sitter parsers, 16 languages. Sirf travsr-core pe depend karta hai — ye invariant hai.

travsr-indexer11,827

Phase A/B orchestration, SCIP/LSIF ingest, import linking, subprocess sandbox.

travsr-plugin-host11,066

Trust boundary. Untrusted Phase B tools yahin chalte hain — bwrap / seatbelt / job objects.

travsr-store9,748

SQLite + WAL. Schema, 18 migrations, FTS5, batch/staging writes, GC.

plugin-protocol / sdk747

Length-prefixed protobuf wire format + thin SDK. Naya language plugin yahin se banega.

Read path

Query → seeds → graph algorithms → token-budgeted context. Product ki quality yahin banti hai.
travsr-retrieval3,439

Algorithms: PPR, PCST, knapsack, k-core, BM25, RBAC filter. Self-contained aur benchmarked.

travsr-rerank713

ONNX cross-encoder via tract. K≈30 candidates, 1200ms circuit breaker.

travsr-mcp17,758

Sabse bada crate. Seed selection, RRF fusion, abstention, 12 MCP tools, sanitization.

Control plane

Graph ko fresh rakhta hai aur user tak pahunchata hai.
travsr-daemon6,063

Background process — file watcher, git hook dispatch, Phase B scheduler, query cache.

travsr-cli7,420

travsr binary. clap subcommands: init, ask, graph, mcp, lang, embed, fsck.

travsr-ipc386

Unix domain socket / Windows named pipe. CLI ↔ daemon transport.

error / config644

Error taxonomy (ADR-004) aur reindex resource governance config.

Ek architectural invariant

travsr-analysis ke lib.rs me likha hai: "this crate depends ONLY on travsr-core. No other travsr-* crate may appear in Cargo.toml." Aur travsr-plugin-host ke doc me: "the ONLY crate in the indexer tier that depends on travsr-plugin-protocol." Ye deliberate boundaries hain — trust boundary ek jagah rehti hai, parsing pure rehti hai. PR me inhe todo mat.
